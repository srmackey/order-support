# Promotions and Discounts

## How do I apply a promo code?
Enter the code in the promo field at checkout before completing payment. Only one code can be applied per order unless otherwise stated.

## Why isn’t my promo code working?
Common reasons: the code has expired, the order does not meet the minimum spend, the item is excluded (e.g., already on sale), or the code has already been used.

## Can I combine a promo code with a sale price?
Most promo codes cannot be combined with sale or clearance pricing. The checkout page will indicate if a code is valid for the items in your cart.

## Do you price-match?
We do not offer price matching with other retailers.
